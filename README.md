# Solicitudes

Aplicación de solicitudes internas del taller de versionamiento · Microcredencial en Programación
No Code - Low Code con IA · Universidad Icesi.

## Cómo la abro
Doble clic en `index.html`.

## Cómo la cambio
No editando archivos: **pidiéndoselo al asistente**. Abre el asistente sobre esta carpeta y
descríbele qué quieres. En `PROMPTS.md` están las frases que vas a necesitar.

## Qué hace hoy
- Registrar solicitudes
- Marcarlas como aprobadas
- Contar cuántas hay y cuántas están aprobadas
- Guardarlas para que no se pierdan al cerrar el navegador

## Qué le falta
Eso lo construyes tú. Empieza por ponerle el nombre de tu área.
